Xác nhận xóa đề thi?

Toàn bộ câu hỏi và kết quả đã làm của học sinh đối với đề này sẽ bị xóa và không thể khôi phục.

Chia sẻ đề thi cho học sinh

Học sinh chỉ cần mở link trên điện thoại hoặc máy tính, nhập tên và lớp là có thể làm bài ngay không cần tài khoản.

Lưu ý: Đề thi nhiều ảnh có link nén khá dài. Hãy cấu hình Supabase (nút đám mây) để tạo link ngắn gọn hơn.

Cấu hình Supabase Cloud (Miễn phí)

Để chia sẻ đề qua link ngắn và đồng bộ kết quả học sinh gửi về máy giáo viên theo thời gian thực, hãy điền thông tin Supabase (miễn phí trọn đời):

Tạo 2 bảng trong Supabase SQL Editor:

create table quizzes (id text primary key, data jsonb);
create table results (id text primary key, quiz_id text, data jsonb, created_at timestamptz default now());
